# MeLauncher — установщики

Здесь только готовые установщики лаунчера MeLauncher (Minecraft Java Edition для macOS и Windows). Отсюда установленный лаунчер сам скачивает обновления.

Скачать последнюю версию: раздел **Releases** → `MeLauncher.dmg` (macOS), `MeLauncher-Setup.exe` (Windows) или `MeLauncher-Portable.exe` (Windows без установки).
